  - KBANK → `AICCKBANK`
  - SCB → `AICCSCB`
  - BAY → `AICCBAY`
  - KTC → `AICCKTC`

  - PAYPAL → `AICCPAYPAL`
  - SIAMPAY → `AICCSPAY`

  `credit_card/jv.py` `BANK_SOURCE_MAP` and `shared/constants/banks.ts` `BANK_SOURCE_MAP`. The
  wizard and email ingest post the same codes, and the contract tests pin them.

  `CARMEN_INTEGRATION.md` §4 item 2 and §5 item 7. Carmen has all 8 codes on every BU.

  - Stored `bu_accounting_configs.file_source`: it is only used for an unknown bank, and the
    Mapping page rewrites it on save.

- **Known effect:** GL history is read from `/spGetListJvBySource/{source}`, so the Mapping page's
  AI Suggest has no history under the new codes at first. It falls back to plain AI until about 3
  new JVs build up per field. This was accepted. Saved mappings and email posting are not affected.
- **Copy:** File Source help text (EN + TH) now shows the new codes.
- **Tests:** backend `test_cc_jv.py` passes 39/39. Frontend `src/features/credit-card` passes
  400/400. `tsc` is clean.
