admin page plus quota editing and credit-balance adjustment. Split the review console

## Quota badge → quota popover: making the top-up route findable

### `10:30` The badge was a link that did not look like one

`#/pricing` has had exactly **one** entry point in the app since `PaymentButton` was deleted
on 07-06 as a duplicate of it: the `REMAIN` badge in the header. That badge was an
`<a href="#/pricing">` whose CSS set `cursor: default`, with no affordance beyond a `title`
tooltip. Customers reached pricing only when a 402 blocked them mid-extraction.

Two findings reframed the fix:

- **Users never see Home.** They arrive via Carmen SSO straight into a wizard, so the real
  surface is the wizard header, not `Home.tsx`. Any Home-side fix is close to worthless.
- **The blocked path already works.** `useOcrExtraction.ts:242` catches 402 with an "Out of
  Documents" modal and a "Buy Credits" confirm. The gap was buying *before* the wall.

A first attempt added a `Top up ›` column inside the badge. It was rejected in review: it
reuses `.ui-quota-col`, so it inherits the same 1px divider and the same 9px uppercase
tracked label as `REMAIN 1527` and therefore reads as a **second readout**, not a button. It
also put Thai (`เติมเครดิต`) into an 8.96px Latin-only micro-label and failed WCAG AA in the
`is-low` state.

Shipped instead: the badge is now a **disclosure button that opens a quota popover**. Goal
was findability, not conversion — a `<button aria-haspopup="dialog">` with a chevron is
unambiguous, and the panel gives the CTA room for a full-size button in either language.

#### Frontend

- `components/common/UsageIndicator.tsx` — `<a>` → `<button aria-haspopup="dialog">` with a
  rotating `ChevronDown`. Popover mechanics (anchor via `getBoundingClientRect`,
  `createPortal`, close on Escape / outside click / outside scroll / resize) copied from
  `NotificationBell.tsx`, which is the established precedent; Escape restores focus to the
  trigger. Panel footer holds real anchors (`#/pricing`, `#/pricing/orders`) so middle-click
  and open-in-new-tab survive the switch away from a link trigger.
- **The panel un-sums REMAIN.** `computeUsageStats` folds three pools (free trial +
  subscription window + top-up credits) into one number, so nobody could see why they had
  1527 or that their plan expires in four days. One row per pool that actually exists, plus
  plan name via `catalogName()` and `period_end` via `formatDate()`, matching
  `OrderHistory`'s `ActivePlanBanner` vocabulary. `usage.freeLeft` / `usage.planLeft` /
  `usage.topupCredits` already existed in both `en` and `th` and were **dead keys** — adopted
  rather than duplicated.
- Skeleton now renders the chevron too. Previously the skeleton was one column and the
  loaded state two, so resolving usage reflowed the header and re-truncated
  `.app-header-title` (`.app-header-actions` is `flex-shrink: 0`) on every page load.
- `styles/components/usage-indicator.css` — `.ui-quota-panel` clones the
  `.notif-bell__panel` shape (the two open side by side in the header, so they must open
  identically). `min-height: 44px` under 768px per DESIGN.md §6. Deleted dead
  `.col-used` / `.col-total` / `.usage-bar-*` rules — unreferenced anywhere in `src`.
- `i18n/dict.ts` — added `quota.triggerAria`, `quota.panelTitle`, `quota.lowHint`,
  `quota.total`; `quota.remain` / `quota.topup` moved off hardcoded English. Dropped
  `quota.linkTitle` (the tooltip was carrying the whole affordance; now redundant).

#### Accessibility — three P1s found while auditing the first attempt

- `styles/base.css` — new `--rose-text` token pair, following the existing `--amber-text`
  precedent for an AA foreground tier. `--rose` is only **3.8:1** on `--card-bg`, which fails
  SC 1.4.3 for the sub-19px text in the `is-low` state, the state that matters most. Light
  `oklch(0.48 0.15 25)` = 6.5:1; dark keeps the current value (already 5.9:1).
- `.ui-quota-label` moved off `--text-4` (**2.4:1** on `--muted` at 9px/700, a pre-existing
  fail) to `--text-3` (~4.6:1).
- Thai label sizing under `[lang='th']`: 0.68rem, `letter-spacing: 0`, `text-transform: none`.
  Uppercase is a no-op on Thai and positive tracking pulls tone marks off their base glyph.
  Fixes a standing violation of DESIGN.md principle 4 (language parity).

#### Tests

`components/common/UsageIndicator.test.tsx` (new, 9 cases): trigger opens the
panel, Escape closes and returns focus, focus moves into the panel on open, only the tenant's
actual pools render rows, a summed REMAIN breaks back into its three pools, a plan with no
`period_end` omits the expiry clause, the low hint appears only when nearly spent, the CTA
routes and closes. `UsageIndicator.test.ts` keeps the pure `computeUsageStats` cases.

### `10:40` Polish pass — three real defects, one of them the original bug

- **`cursor: default` came back.** `.ui-quota--trigger { cursor: pointer }` had been written
  *above* `.ui-quota { cursor: default }`. Equal specificity, so source order decided and the
  hand cursor lost — the exact bug this whole change set out to fix. Trigger block moved below
  `.ui-quota`, and `cursor: default` deleted outright (a `<div>` skeleton with
  `pointer-events: none` never needed it).
- **Keyboard users could not reach the CTA.** The panel is portaled to the end of `<body>`, so
  Tab from the trigger walked the rest of the header instead of entering the panel. Panel now
  takes `tabIndex={-1}` and receives focus on open; Escape hands it back. Both covered by
  tests.
- **`formatDate(null)` renders `—`**, so a plan without `period_end` would have read
  "Professional · Active until —". Guarded, matching `ActivePlanBanner`'s own check.

Smaller items from the same pass:

- `:active { transform: scale(0.97) }` on the trigger. It became a button and had none;
  DESIGN.md §6 requires all five states, and `.app-header-back` (its neighbour) sets the
  precedent.
- **Label contrast finished properly.** `--text-3` on `--muted` is 4.33:1, still short of AA at
  that size. Root cause was the `--muted` fill on `.col-remain`, which existed only to separate
  it from `col-used` / `col-total` — both long dead. Dropped it, so the label sits on the card
  face at 4.65:1, and the low state takes `--rose-text` (5.99:1 on `--rose-light`).
- Label size 0.56rem → **0.68rem for both languages**, which is DESIGN.md §3's stated label
  floor; the component had been running under its own system's minimum. The Thai override now
  only resets tracking and case, not size.
- `.ui-quota-row.is-total` replaces `:last-child`, so adding a pool row later cannot silently
  move the total treatment. Made `position: sticky` since the rows can now scroll.
- Panel gained `max-height: calc(100vh - 5rem)` + scrolling rows. Landscape tablet is ~400px
  tall and the footer was landing offscreen.
- Order-history link uses `order.title` ("Order history") instead of `nav.history`
  ("History"). The latter is a tab label on the pricing page where neighbouring tabs supply
  the context; a lone link has to stand alone.
- Dropped the `AnimatePresence` wrapper. Its single child never unmounted and no `exit` was
  defined, so it did nothing.

### `10:50` Internal balance of the trigger

Adding the chevron unbalanced the button, and the cause was **two padding owners**. The column
carried `0.3rem 0.75rem` and the chevron `0 0.5rem 0 0.4rem`, which measured out as:

```text
edge │12px│ REMAIN 1542 │12px│6.4px│ ⌄ │8px│ edge
```

Left inset 12px, right inset 8px, and 18.4px between the number and the glyph. The readout sat
left-heavy with the chevron adrift.

- **The button now owns all inner spacing**: one `padding: 0.3rem 0.6rem 0.3rem 0.75rem` plus
  `gap: 0.4rem`; padding removed from both `.ui-quota-col` and `.ui-quota-chevron`. Right inset
  stays tighter than left on purpose, since a chevron carries its own optical whitespace.
  `align-items: stretch` → `center` (nothing has a column fill to stretch any more).
- **Chevron is `--text-3` at rest**, taking `--primary` on hover and while open. Two Carmen Blue
  elements inside one small badge had the glyph competing with the number for weight; DESIGN.md's
  One Voice Rule wants the number to be the single accent.
- Chevron 13px → **14px at strokeWidth 2.25**, matching `ArrowLeft` in `.app-header-back`, the
  icon physically closest to it.
- `.ui-quota-label` gets `margin-right: -0.1em`. Its `letter-spacing: 0.1em` added tracking after
  the final letter, so the label's ink centred ~0.5px left of the number above it. Reset under
  `[lang='th']`, where tracking is already 0.
- **The low state tints the whole badge** instead of `.col-remain`. Tinting one column was
  another 3-column-era habit; with a lone readout it left a rose block stopping two-thirds
  across the button.
- Deleted `.ui-quota-col + .ui-quota-col` (only one column exists) and the entire
  `[data-theme='dark']` block — `--card-bg` / `--border` / `--rose-light` / `--rose-mid` are
  already theme-aware, so those three rules restated themselves. Removing them also cleared a
  specificity trap: the dark `.ui-quota` rule would have outranked `.ui-quota.is-low` on source
  order once the tint moved up.
- `min-height: 44px` moved from `.ui-quota--trigger` to `.ui-quota` so the skeleton matches the
  loaded height on mobile, and the mobile query now tightens padding horizontally only.

### `11:00` Skeleton correctness + remaining debt cleared

Two real defects in the loading state, both pre-existing:

- **The skeleton never cleared when unauthenticated.** `loading` starts `true`, and the fetch
  effect returns early on `!isAuthenticated` — before the `finally { setLoading(false) }` — so
  the badge sat in the header as a permanent skeleton. Now returns `null`. (The no-token path
  was already fine: `setLoading(false)` lives in `finally`, so it runs regardless.)
- **The badge still resized on resolve.** The placeholder was a single `—` (~1ch) and the real
  value is up to 4 digits, so the width jumped and dragged `.app-header-title`'s ellipsis with
  it — the same reflow the chevron-in-skeleton fix was meant to end. `.ui-quota-value` now
  reserves `min-width: 4ch` (mono, so `ch` is exact) and centres, which also holds the width
  steady across every `ocr:quota-refresh` as 27 becomes 1542.

Presentation, aligned to the project's own skeleton convention:

- **A faded `—` reads as "no data"; this is loading.** The placeholder is now a shimmer block
  reusing `sk-shimmer` from `page-skeleton.css`, so it matches every other skeleton in the app.
  The global `prefers-reduced-motion` rule stops it.
- Dropped the blanket `opacity: 0.45`. The label is static and known, so it renders for real;
  only the unknown number shimmers, and only the chevron dims (the badge isn't pressable yet).
  Nothing pops when usage resolves.

Also removed the last three dead `usage.*` keys (`runningLow`, `freeTrial`, `renews`) now that
this component revived the other three, and renamed the block comment to say where the
survivors are actually used.

355/355 tests green (2 new: unauthenticated renders nothing, skeleton keeps the loaded badge's
element shape), `tsc --noEmit` clean, `npm run build` clean, ESLint clean.
