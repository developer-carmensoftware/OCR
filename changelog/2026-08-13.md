## Backend

`10:23` `GET /api/v1/carmen/notifications?uri=&bu=&since=` → `{"has_notification": bool}` — interim
poll substitute for the unbuilt `CARMEN_INTEGRATION.md §3.2` webhook (`notification.created`
was only ever a proposal; nothing sends it). Same Carmen-token auth as `/settings`,
read-only — polling never marks anything read.

- **A badge, not a feed.** §3.2's own payload deliberately carries no message text, so the
  badge only ever needed a bool. The full list stays the in-app bell's endpoint
  (`GET /api/v1/notifications`) rather than becoming a second copy of that contract to keep
  in sync.
- `services/notification_service.py` — new `has_notification()`, one `EXISTS` instead of
  `list_notifications`' 50-row fetch + count. `since` given → anything created after it;
  omitted → anything unread. **`since` is the mode that works**: unread only ever clears
  through our own bell, so for a BU whose staff live in Carmen and never open our app the
  badge would otherwise go true on the first document and stay true forever. The cursor is
  the caller's; we store no state for it.
- `services/email_ingest_service.py` `_finish()` now calls `notification_service.notify()`
  for `status in ("posted", "failed")`, writing `document_posted`/`document_failed` rows so
  the endpoint has email-automation outcomes to report at all. `skipped` stays silent on
  purpose — same rationale as the existing `except _Skip` handling (a customer's own
  filename/sender rule saying "not this file" isn't a failure).
- `routers/email_automation.py` — new `read_notifications` route next to `read_settings`,
  no new auth/rate-limit code (`_caller`/`_resolve` already cover it).
- Docs updated to match: `docs/CARMEN_INTEGRATION.md` §3, `docs/CARMEN_API_SPEC.md`
  (bumped to v4.2, new §6 for Carmen's own developers),
  `docs/email-automation/03-api-reference.md`.
- Still open for Carmen: whether they want §3.3 `document.posted`/`document.failed` (the
  per-document detail) as a real webhook. This endpoint deliberately does not pre-empt that.
