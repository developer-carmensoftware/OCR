# 2026-07-01

## Infra / CI-CD

`10:00` **feat(ci-cd): gated deploy pipeline + CodeQL + secret scanning; drop unused Docker** (PR #17)
- **New `deploy.yml`** — one workflow, both GitHub Environments (`dev`→staging, `main`→production): runs `supabase db push` first, then fires the Render deploy hook, then smoke-tests `/api/v1/health`; on `main` also cuts a GitHub Release from that day's `changelog/`. Backend `render.yaml` set `autoDeploy: false` so code never ships ahead of its migration (safe under expand/contract).
- **New `codeql.yml`** — CodeQL for `python` + `javascript-typescript` on PR + push + weekly.
- **`ci.yml` hardening** — top-level `concurrency` (cancel superseded runs) + least-priv `permissions: contents: read`; removed the unused `docker` build job; fixed the misleading dummy `DATABASE_URL` (`mysql+aiomysql` → `postgresql+asyncpg`).
- **New CI jobs** — `migrations-validate` (applies `schemas/` + `migrations/` + seed on the real Supabase stack via `supabase db reset`); `gitleaks` secret scan run as the **free binary** (the `gitleaks-action` wrapper requires a paid license for orgs); `changelog-check` (fails a PR that touches no `changelog/` file, escape hatch `skip-changelog` label).
- **`.gitleaks.toml`** — allowlist for the intentionally-committed placeholders / CI dummies.
- **Deleted** `backend/Dockerfile`, `frontend/Dockerfile`, `docker-compose.yml` — Render/Vercel use native runtimes; `docker-compose.yml` still referenced MariaDB + upload volumes that no longer match the Postgres / no-file-storage architecture.
