# 2026-07-13

## `09:53` Admin login: email → username

Admin dashboard login switches from email+password to username+password. The
`admin_users.email` column was already a plain unique `varchar(255)` with no
email-specific validation and no mail ever sent to admins — a pure login
handle — so this is a rename, not a schema redesign. Existing admin accounts
keep their current value as-is (e.g. `admin@carmen.com` simply becomes that
account's username); matching stays case-insensitive.
