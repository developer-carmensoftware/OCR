## `09:53` Admin login: email → username

Admin dashboard login switches from email+password to username+password. The
`admin_users.email` column was already a plain unique `varchar(255)` with no
email-specific validation and no mail ever sent to admins — a pure login
handle — so this is a rename, not a schema redesign. Existing admin accounts
keep their current value as-is (e.g. `admin@carmen.com` simply becomes that
account's username); matching stays case-insensitive.

## `16:40` Dependabot: fix changelog-gate failures, reduce PR noise

Every open Dependabot PR was failing CI's `changelog-check` job — it requires a
`changelog/` touch with `skip-changelog` label as escape hatch, but the label
didn't exist in the repo and Dependabot never applied it.

### Infra

- `16:40` Created the `skip-changelog` GitHub label; applied it to all 12 open
  Dependabot PRs and re-triggered the 3 that had already failed CI.
- `16:40` `.github/dependabot.yml`: every update block now sets
  `labels: [..., "skip-changelog"]` so future Dependabot PRs self-skip the gate.
- `16:40` Added a `*-minor` catch-all group (patterns `["*"]`,
  `update-types: [minor, patch]`) to the pip and npm blocks, and an `actions`
  group to the github-actions block — bundles routine bumps into one weekly PR
  per ecosystem instead of one PR per dependency. Tidied `sqlalchemy-stack`
  patterns (`aiomysql`/`alembic` aren't used; added `asyncpg`).
- `16:40` `tailwindcss` major bumps ignored in dependabot.yml — 3→4 broke the
  Vercel build (PR #43); 3.4.x patches still flow via `frontend-minor`.
- `16:40` New `.github/workflows/precommit-autoupdate.yml`: weekly
  `pre-commit autoupdate`, opens a `skip-changelog`-labeled PR if
  `.pre-commit-config.yaml` hook pins moved — Dependabot has no pre-commit
  ecosystem, so this covers the one manifest it can't reach.

Coverage check: all git-tracked dependency manifests (pip x2, npm, github-actions)
already had a matching `.github/dependabot.yml` block — no missing ecosystem, only
the config-quality gaps above.
