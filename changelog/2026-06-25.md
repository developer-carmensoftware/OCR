`fix(layout): pricing cards — equal columns so the Standard card sits dead-center`
- `pricing.css` — `.plan-grid--5` / `--4` now use `repeat(N, minmax(0, 1fr))` instead of `repeat(N, 1fr)`. Plain `1fr` is `minmax(auto, 1fr)`, so cards with wider content (annual "/yr Save 10%" price + pill) stretched their own column; columns ranged 189–237px (48px spread), pushing the centered Standard card off true center. `minmax(0, …)` forces exactly-equal columns. Diagnosed via live DOM probe (grid + every ancestor measured L=R=0 → not a centering/scrollbar issue; the column widths were the culprit).
