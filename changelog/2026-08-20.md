# 2026-08-20

## Frontend

- `09:35` **Consent modal no longer flashes on every load.** (`65f436f`) `useUserConsent` set
  `hasConsented=false` *before* awaiting `getConsentStatus`, so the modal rendered and
  then vanished once the server confirmed an existing `consent_logs` record. State is now
  tri-state (`null` = check in flight) and the hook returns `showConsent`, which is only
  `true` after the server actually says no record exists — ask first, show second.
  Network failure still prompts (can't prove consent → don't silently skip the gate).
  Files: `hooks/useUserConsent.ts`, `components/common/ConsentGate.tsx`,
  new `hooks/useUserConsent.test.ts` (3 cases, covers the in-flight regression).

- `09:55` **Idle tabs stop hammering `/notifications` and `/maintenance/status`.**
  `MaintenanceGate` polled every 30s unconditionally; it now ticks only while the wall is
  up or a scheduled window is still ahead — the `ocr:maintenance` event (fired by any 503)
  already raises the wall instantly, and `focus`/`visibilitychange` picks up a window
  scheduled while the tab sat idle. Same pattern `useOrderHistory` already uses. Notification
  bell poll 60s → 5 min (nothing there is time-critical; the focus refresh covers active
  users). An idle tab now makes **zero** background requests instead of ~90/hour.
  Files: `components/common/MaintenanceGate.tsx`, `hooks/notifications/useNotifications.ts`.
