## Security hardening, round 2 — PR 2: retention (#322, merged 10:50)

`10:20` Decision-log #50, PR 2.

- **Ingest mailbox keeps 14 days.** `imap.purge_expired`:
  - moves every message that arrived `BEFORE since_arg()` to the Trash. That is the exact
    complement of the poll's `SINCE`, so nothing a poll could still pick up is touched;
  - finds the `\Trash` folder through `LIST`, then `UID MOVE` in chunks of 100. Fallbacks:
    COPY + `\Deleted` + EXPUNGE without MOVE, and a plain delete with no Trash;
  - runs as `POST /api/v1/carmen/email-ingest/purge` (job token; `?dry_run=true` counts only),
    scheduled daily at 04:00 UTC by migration `20261030000100`.

    code asks `CAPABILITY` after login.

  04:20 UTC.

## Security hardening, round 2 — PR 3: keys (#323, merged 10:50)

`10:40` Decision-log #50, PR 3.

- **One key path, `app/utils/crypto.py`.** A `MultiFernet` over `SESSION_ENCRYPTION_KEY` plus the
  new **`SESSION_ENCRYPTION_KEYS_OLD`** (decrypt-only, comma-separated; a bad value stops the
  boot).
  - `encrypt/decrypt_carmen_token` use it when no key is passed: sessions, the BU credential,
    PDF passwords.
  - `EncryptedJSON`/`EncryptedText` use it too.
- **Rotate tool:** `POST /api/v1/admin/encryption/rotate` (`?dry_run=true`; job token or
  `configs:write`).
  - Re-encrypts every token the primary key cannot open: the encrypted columns, the two
    credential columns, and each rule's `pdf_password_enc`.
  - Raw reads and writes, compare-and-set. `unreadable` counts tokens no key opens.
  - Runbook: **`docs/KEY_ROTATION.md`**.
- **`email_documents.error_message` encrypted** (`EncryptedText`, no migration). It names the
  addresses a refused mail carried, and reviewers still see them. Two QA scripts read it through
  `read_text` now.
- **Tests:**
  - backend 1999 pass (`test_key_rotation.py` unit, plus a boot guard on a bad old key);
  - real DB `tests/tenancy/test_key_rotation.py` 2/2 on local Supabase: every token kind under an
    old key reads mid-rotation, rotates, and reads under the new key alone. It fails when
    `_rotate` does nothing.
- **E2E: the whole runbook on the local stack** (`scripts/qa/key_rotation_ui.mjs`).
