# 2026-08-11

## `11:45` Frontend — app header badge is one accent color, not per-module hues

`.app-header .logo-box` (`AppHeader` — used by Credit Card, AP Invoice, Mapping, WhatsNew,
Pricing, Order History) used to theme `--module-accent` per `data-module`, and in dark mode
each module's variant had its chroma dropped to ~0.05, reading as flat gray instead of blue.
Collapsed to a single accent (`--primary` in light, `--primary-fill` in dark — the same blue
already used on filled buttons) shared by every module, split only by theme.

- [`frontend/src/styles/layout.css`](../frontend/src/styles/layout.css) — removed the three
  `[data-module='...']` override blocks (light and dark); `--module-accent` now set once at
  `.app-header` and once at `[data-theme='dark'] .app-header`.
- No other CSS reads `data-module`, so no other page/component is affected.
