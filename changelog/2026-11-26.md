## Typing in inputs: JV amount field and dialog focus (branch `fix/typing-jv-amount-and-modal-focus`)

Found by the input-field sweep (`scripts/qa/input_fields_ui.mjs`), which types key by key in a real browser; the unit tests set whole values with one change event and could not see either.

- `09:30` **Frontend (`JvEditor.tsx`, review dialog):** the JV debit/credit amount field reformatted its own text on every keystroke, so selecting an amount and typing `1200` left `1.00` (the first key was reformatted under the caret), Backspace at the end of `1,000.00` did nothing, and clearing the field made the leg 0, dropped its row and took the input with it. The field now keeps a draft while it has the caret: what is typed stays as typed, a number is committed upward as it forms (so Balanced/Out-of-balance follows), a zero waits for blur, and the figure is formatted on blur. Focusing and leaving without typing no longer rewrites the figure. User-visible → park for the monthly release note (Enhancements, "Review amounts (AI JV Automation)").
- Tests: `ReviewDocument.test.tsx` › "typing an amount on the JV, key by key" (the first two fail on the old code).
- `09:50` **Frontend (`CustomModal.tsx`):** the dialog's 50 ms "initial focus" timer lived in the same effect as its keydown handler, whose dependencies include `onCancel`/`onConfirm`. Callers pass inline arrows, so every render of the page behind re-armed the timer. In the late input-tax dialog (Vendor, Tax ID and Branch update the parent on each key) focus jumped to the "Record input tax" button ~50 ms after the first keystroke, so typing "Siam Paper" lost everything after "S" and the space pressed the button and filed the record with vendor "S". The timer now depends on `show`/`inputLabel` only and fires once per opening. User-visible → park for the monthly release note (Enhancements, "Record input tax (AI JV Automation)").
- Tests: `CustomModal.test.tsx` › "focus while the page behind re-renders" (the first fails on the old code). Browser: `scripts/qa/input_fields_ui.mjs` late section C2a–d all OK after the fix.
