# 2026-11-03

## CI: Supabase CLI pinned to 2.121.0 (branch `ci/pin-supabase-cli`)

`15:31` **Infra.** Supabase CLI 3.0.0 came out today and refuses this repo's
`supabase/config.toml`: *"[inbucket] in supabase/config.toml is no longer supported. Use
[local_smtp] instead."* `ci.yml` installed `latest`, so the **Migrations (Supabase)** job
failed on every PR (first seen on #336), whatever the PR changed.

- `ci.yml`: `supabase/setup-cli` is now pinned to `version: 2.121.0`, the version the local
  recipe uses.
- The job's own steps (`supabase start`, `db reset`, `test db`) pass locally on 2.121.0.
- Moving to 3.x goes with a `config.toml` migration, in its own PR.
