## Backend (branch `feat/ai-status-v2`)

`14:01` **`GET /api/v1/carmen/ai-status` v2: the numbers Carmen's popup rule reads, behind the user's Carmen token** (`648f520a`)

The contract was settled in a grilling on 2026-10-19. There is no Jira ticket; the spec is Carmen's popup journey table.

- **Carmen decides the popup now**, with its own rule: Never Used 0/30 · Trial Active 1–24/30 · Near Limit 25–29/30 · Exhausted 30/30 · paid → none. We send only what that rule reads:

  ```json
  {"paid": false, "trial": {"used": 26, "total": 30}, "modules": {"ap_invoice": 2, "jv": 24}}
  ```

  - `paid`: an active plan, or any top-up ever bought.
  - `trial`: `null` once paid, because bought credits make 30 − balance meaningless.
  - `trial.used` = 30 − credits left, clamped 0–30 (`trial_used()` in `services/shared/credits.py`). It does not read `SUM(charged_docs)`: a refund returns the credit but never touches `ocr_tasks.charged_docs` (dev `demo`: 21 charged, 20 by credits).
  - `modules`: documents per product, all time, as `#/admin` counts them (`jv` = every Credit Card module). A product with none is absent.
- **Removed:** `stage`, `stage_no`, `docs_used`, `docs_remaining`, `ai_stage()`, `NEAR_LIMIT_USED`, `AI_STAGE_NO`. They came from #288/#294, and no consumer had wired them yet.
- **Auth is now required**, the email Settings API way (`_caller`/`_resolve`): `Authorization: <the user's Carmen token>`, proven against the BU's Carmen; our admin JWT (`configs:write`) works too.
  - The response no longer leaks to anyone who guesses a (host, bu).
  - The boundary is the host, i.e. the corporate group.
  - The endpoint's own 300/min ceiling is gone; `_caller`'s 20/min/IP and 300/min global probe ceiling cover it.
  - `Cache-Control: private, max-age=300`.
- **A BU that never opened the app** reads `{"paid": false, "trial": {"used": 0, "total": 30}, "modules": {}}` once the token is proven against the `uri` it names. Nothing is written. A `ponytail:` notes that this path has no rejection cache until #293's `_prove()` lands.
- **QA caveat:** `-xntb` has no `TRUST_PROXY`, so every QA browser shares one 20/min bucket.
- `tests/unit/test_ai_status.py` rewritten (15). Full suite: 1845 passed, 88 skipped.
- No release note (nothing changes inside our app); no VERSION bump (batched per release).
