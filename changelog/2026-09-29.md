# 2026-09-29

`09:41` **Top-up packs: a card per pack with its saving, motion from the system's own
vocabulary, and the fixes a Playwright pass turned up.** *(branch `design/topup-pack-rail`, follows
#268)*

Supersedes #268's compact 4-up cards. The design went through two rejected rounds first: a joined
rail, then a hover highlight that glided under the pointer (off-system, since motion here conveys
state). Both are in the branch history.

- **Frontend: `PackList.tsx` + `styles/pages/pricing.css`.**
  - Each pack is its own card, spaced and lifted like `.plan-card`: 1rem gap, `--radius-lg`,
    `--shadow-card`, and the same pointer-gated hover (−2px, `--shadow-card-hover`, `--border-hi`).
    The whole card is the button and presses to 0.98.
  - No icon. From 561px the card shows centered credits, the price, the per-doc rate, then a
    **Save N%** chip on its own line. The chip is each pack's per-doc saving against the dearest
    pack, derived from the catalog, so a reprice moves it.
  - "Best value" is a solid `--emerald-fill` pill, so it never reads as another save chip.
  - Rows ≤560px.
- **Motion.** Entrance uses the plan grid's own variants, now in `features/billing/motion.ts` and
  shared by both.
  - Revealed on scroll, on a `.pack-cell` wrapper, because framer's inline transform on the card
    itself would override the CSS hover lift.
  - Gated by the page's `useEntrance('pricing')`: first view only, and never with reduced motion.
- **Fixes from the Playwright pass.**
  - **Order amounts show satang.** `฿1,059.3` becomes `฿1,059.30` in the pending-order banner,
    order history, admin order table, workspace list and KPI cards. `formatThb(x, true)`; the
    default stays whole for catalog prices. +1 test.
  - **Save chip on its own line in every language.** It used to wrap only when it didn't fit, which
    left Thai cards a line taller than English at 4-up.
  - **Load errors say it once.** "Failed to load plans: Failed to load plans (500)" becomes "…: HTTP
    500". The Thai message no longer carries an English sentence inside it. Same for order history.
- **Found, not code:**
  - `20260928000000_reprice_pack_micro` was applied to the shared DB from #268's branch before #268
    merged. `supabase db push` from `main` fails with `LegacyDbPushMissingLocalError` until #268 is
    in.
  - That migration didn't set `credit_packs.updated_at`, so the row still reads 2026-09-24. The
    next reprice migration should `set updated_at = now()`.

  - build, vitest, lint, prettier, contrast and backend pytest;
  - Playwright against a real session on `#/pricing` (1440/900/800/400, EN/TH, dark, reduced
