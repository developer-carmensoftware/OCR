## `04:17` Dark-mode contrast fixes

### Frontend

- `styles/components/user-consent.css` — consent-modal callout text was invisible in dark

  because the global `[data-theme='dark'] th` `!important` rule in `base.css` leaked into

  the proforma's theme-fixed "paper" palette.

## `04:02` Admin frontend audit — a11y, dark-mode & consistency fixes

Impeccable-style pass over all `#/admin/*` pages. The surface was already strong (tokens,
skeletons, skip-link, i18n, reduced-motion); these are the gaps against the project's own
DESIGN.md rules and WCAG AA.

### Frontend

- `components/admin/DataTable.tsx` — sortable column headers are now real `<button>`s
  (keyboard/screen-reader operable) with `aria-sort` on the active `<th>`; sorting was
  mouse-only across every admin table. Padding moved onto the button so the whole header
  stays the hit area (`admin.css` `.admin-th-sort`).
- `components/admin/MetricChartImpl.tsx` — recharts Tooltip and X/Y axis ticks now use theme
  tokens (`--card-bg`/`--border`/`--text-*`) instead of recharts' white-box + gray-text
  defaults, which ignored dark mode. Series line/bar colors left as-is (legible on the card
  surface in both themes).
- `styles/pages/admin.css`:
  - `@media (max-width: 768px)` — 44px minimum tap targets on nav items, pagination, selects,
    logout/icon/danger buttons (DESIGN.md mandate that wasn't enforced).
  - Mobile sidebar (`≤900px`) flattens grouped sections (`display: contents`, section labels
    hidden) into one clean scroll row.
  - Dropped the `.admin-page-title` gradient accent bar so the old `.admin-page-*` header
    matches the newer `.ui-page-*` kit — no title jump between migrated/un-migrated pages.
  - `.tenant-chip.danger` + `.alert-severity--critical/--warn` routed through rose/amber
    tokens with explicit dark-mode foreground overrides (were hardcoded `#f43f5e` / dark oklch
    with no dark variant → contrast risk at night).
  - `.admin-chart-title` status dot no longer blinks forever (decorative motion).
