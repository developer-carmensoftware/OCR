## Backend + Frontend + DB (PR #317, merged `80786049`)

(input-tax service + routes), `c35c2039` (email stamping), `259732f6` (activity rows),

- **Owed is one rule for both sources:** JV posted, VAT > 0, input tax not resolved. Wizard
  Skip, an unticked approve box ("not now", no longer "keyed by hand") and a refused or failed
  filing all count.
- **DB:** migration `20261029000000_credit_cards_input_tax_keyed.sql` adds
  `credit_cards.input_tax_by` (Carmen user id) and `input_tax_keyed` (true = marked keyed by
  hand, no Carmen call). **Not pushed yet** — `supabase db push` before the backend deploys.
- **Email:** `_stamp_input_tax` (ledger.py) writes `commis_amt`/`tax_amt` (from `[total_row]`
  for the settlement report), `doc_no`/`doc_date`/`branch_no` as posted, and `input_tax_at`
  only when filed — after `_finish`, so the card owes nothing until the row's note is written.
- **Late filing:** `file_input_tax_for_card` takes the dialog's corrections (vendor, tax ID,
  profile, branch) and a period from `claim_periods` (doc month → +6, capped at the current
  Thai month; Revenue Code s.82/3); past the window it refuses. `mark_input_tax_keyed` settles
  it with no Carmen call. Resolving clears the posted email row's note.
  `build_input_tax_payload(period=)` moves the period only; the invoice date stays the doc's.
- **API:** `GET /activity/{card_id}/input-tax` returns the dialog prefill when owed (`{owed}`
  alone otherwise — the wizard's restore check is unchanged); `POST` takes an optional
  `LateInputTaxIn`; new `POST …/input-tax/keyed`. Activity rows carry `card_id`; email rows
  answer `input_tax_owed` from their card (one bulk lookup per page).
- **Frontend:** "Record input tax" opens the approve screen's `InputTaxPanel` (`standalone`,
  `periodSlot`) in a `CustomModal wide` (+ `confirmDisabled`): identity/profile/branch editable,
  amounts locked, period picker, "Keyed in Carmen already". The row prints the server's reason
  or "input tax not recorded", never both. Skip copy and the unticked box say it can be
  recorded later. EN + TH.
