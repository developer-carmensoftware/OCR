# 2026-08-25

## Refactor audit — Tier 1: dead code

`10:30` A maintainability audit of the whole repo (23k LOC backend, 42k frontend) found
much less rot than expected: **0 unused i18n keys** out of 1,188, 3 over-exported
frontend symbols out of ~600, 0 TODO/FIXME, and all three CLAUDE.md conventions
(no `BaseModel` in routers, no `HTTPException` in services, single `AsyncOpenAI` factory)
held with zero violations. This is the first of four planned refactor PRs and removes
only what is provably unreferenced.

### Backend

- **Deleted the legacy master-key admin auth.** `routers/admin/deps.py` carried
  `require_admin_key()` and `require_admin()` — both self-labelled as
  backward-compat ("remove in Phase 2"; "used by maintenance.py which has no session
  dep"), and both with **zero references** anywhere in app or tests. `maintenance.py`
  had long since moved to `require_maintenance_auth()`.
- **Dropped `master_api_key` with them** — those two functions were its only readers.
  `MASTER_API_KEY` is gone from `.env.example` and from `render.yaml` (where it was a
  `sync: false` secret Render prompted operators to set on every deploy, for a
  credential path nothing served). Safe because `Settings.Config.extra = "ignore"`:
  an env var still set on a live service is ignored, not a boot failure.
- **Removed unread settings** `app_host`, `app_port`, `admin_jwt_ttl_hours`
  (`config.py`). `run.py` hardcodes port 8010 — `APP_PORT` had been documentation of a
  var nothing read. Purged from `.env.example`, `CLAUDE.md`, `README.md` and the SRS
  env table.
- **Removed `get_all_tenants()`** (`app/database.py`) — zero references.

### DB

- **`20260825000000_drop_retired_quota_tables.sql`** — drops `quotas`, `quota_usage`
  and the `quotaperiod` / `quotametric` enums. `20260813000100` moved the free-trial
  allowance into `tenant_credits` and kept the tables one release for reversibility;
  that release shipped. Confirmed unreferenced: no ORM model, no raw SQL. Charging runs
  entirely through `consume_document()`.
- Deleted `supabase/schemas/40_quotas.sql`, as CLAUDE.md required in the same change.

### Frontend

- **Un-exported three local-only symbols** — `DAY_MS` (`PeriodPicker.tsx`), `slipIsPdf`
  and `SlipSkeleton` (`SlipViewer.tsx`). All three are used inside their own file, so
  this narrows the public surface; nothing is deleted.

### Docs

- `CLAUDE.md`: the Quotas row in the DB layer table is gone and the "Two document pools"
  entry now records the drop migration instead of scheduling it.

**Verification:** `ruff check app/` clean · backend pytest exit 0 · `npm run build`
clean · 501 frontend tests in 49 files pass · app boots with `MASTER_API_KEY` absent
(127 routes).

No `VERSION` bump and no `releaseNotes.ts` entry — refactors bump nothing, and none of
