## `02:41` Credit Card OCR: fixed columns again, blank amounts show `0.00`

Reverts the per-format column-hiding added `2026-07-03 12:13`. The Details table's
`visibleColumns` filter hid any amount column that was `0`/blank on every row, so the
column set varied by document type — payment-gateway fee invoices (KTC/GHL/PayPal/
SiamPay) always have `Net Amt = 0` and lost that column. Per user request the table
now always renders the same fixed 5 columns regardless of bank/gateway, and any empty
amount cell displays `0.00`.

## `10:47` Fix: "View Document" preview auto-opening the browser print dialog

Some uploaded PDFs (bank/gateway statements carrying an embedded `/OpenAction → /Print`)
popped the browser print dialog every time their preview iframe rendered. Root cause:
`6932ba0` (2026-06-30) removed the iframe `sandbox` so Edge would render PDFs — but that
sandbox's absent `allow-modals` had been *suppressing* the PDF's auto-print. Re-adding
`sandbox` isn't viable (Edge refuses to render PDFs in any sandboxed iframe, even with
`allow-same-origin`). Instead we strip the auto-open action from a throwaway copy before
the viewer sees it.

- `10:47` `lib/pdfPreview.ts` (new): `stripAutoOpen(bytes)` deletes catalog `/OpenAction`
  and `/AA` via `pdf-lib` (already a dep); `sanitizedPdfUrl(file)` returns a cleaned blob
  URL, falling back to the raw file URL if the PDF can't be parsed.
- `10:47` `hooks/credit-card/useFileUpload.ts`, `hooks/ap-invoice/useAPExtraction.ts`:
  route the raw-PDF preview through `sanitizedPdfUrl` (now async). The page-selected
  preview (`selectedPagesToPdfUrl`) was already immune — it rebuilds into a fresh doc.
- Admin `OrderWorkspace` PDF iframe left as-is (our own proformas / image slips, cross-
  origin signed URLs where a blob rewrite doesn't apply).

Verified: new `lib/pdfPreview.test.ts` (builds a print-on-open PDF, asserts the action is
gone after stripping); `tsc --noEmit` clean; `eslint` 0 errors on changed files;
`useFileUpload` + `useAPExtraction` + `pdfPreview` suites 37/37 pass.
