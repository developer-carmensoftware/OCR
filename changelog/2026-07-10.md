## `02:41` Credit Card OCR: fixed columns again, blank amounts show `0.00`

Reverts the per-format column-hiding added `2026-07-03 12:13`. The Details table's
`visibleColumns` filter hid any amount column that was `0`/blank on every row, so the
column set varied by document type — payment-gateway fee invoices (KTC/GHL/PayPal/
SiamPay) always have `Net Amt = 0` and lost that column. Per user request the table
now always renders the same fixed 5 columns regardless of bank/gateway, and any empty
amount cell displays `0.00`.
