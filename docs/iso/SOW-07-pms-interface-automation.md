# 1. วัตถุประสงค์ และผู้ใช้งาน

รายได้รายวันของโรงแรมถูกบันทึกในระบบบริหารโรงแรม (PMS) หลังปิดรอบ Night Audit แล้วต้องนำเข้าบัญชีแยกประเภททั่วไป (GL) รายการนี้พัฒนา Interface ที่แปลงข้อมูลรายได้รายวันเป็น JV เข้า GL อัตโนมัติ ลดการคีย์ซ้ำและทำให้ยอดตรงกับ PMS ทุกวัน
