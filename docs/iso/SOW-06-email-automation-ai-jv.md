# 1. วัตถุประสงค์ และผู้ใช้งาน

ธนาคารและผู้ให้บริการ Payment Gateway ส่งใบกำกับภาษีมาทางอีเมล เจ้าหน้าที่ต้องดาวน์โหลดไฟล์แล้วนำเข้าระบบทีละฉบับ รายการนี้ให้ระบบดึงเอกสารจาก Mailbox ทางการเงินเอง ส่งเข้ากระบวนการอ่านด้วย AI และสร้าง JV โดยเจ้าหน้าที่ไม่ต้องโหลดไฟล์
