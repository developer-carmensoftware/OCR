# 1. วัตถุประสงค์ และผู้ใช้งาน

ใบแจ้งหนี้และใบกำกับภาษีซื้อจากคู่ค้าของโรงแรมไม่มีรูปแบบมาตรฐาน เจ้าหน้าที่ต้องคีย์ข้อมูลและจับคู่ผังบัญชีเองทีละใบ รายการนี้พัฒนาระบบที่อ่านเอกสารเหล่านั้น สกัดข้อมูลสำคัญ แล้วบันทึกตั้งหนี้เจ้าหนี้การค้า (AP Invoice) ใน Carmen ERP ผู้ใช้คือเจ้าหน้าที่บัญชีเจ้าหนี้
