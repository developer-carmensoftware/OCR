# 1. บทนำ

## 1.1 วัตถุประสงค์

ทุกงานของระบบที่เรียก AI มีต้นทุน งานนี้กำหนดว่า BU จ่ายค่าการอ่านเอกสารอย่างไร ซื้อโควตาเพิ่มอย่างไร และใช้ module ใดได้บ้าง โดยแบ่งเป็นสามส่วน:

- **กลไกหักเอกสาร** (FRD-04): การอ่านเอกสาร 1 ชิ้น หักจากกระเป๋าไหน และคืนเมื่อใด
- **การซื้อแพ็กเกจ** (FRD-05): ตั้งแต่เลือกแพ็ก ออกใบเสนอราคา แนบสลิป จนทีมงานอนุมัติและโพสต์ลูกหนี้เข้า Carmen
- **สิทธิ์การใช้ module** (FRD-06): BU นี้ใช้ฟีเจอร์นี้ได้ไหม

## 1.2 ผู้ใช้และบริบท

- **ลูกค้า (BU):** ซื้อแพ็กผ่านหน้า `#/pricing` แนบสลิป และดูประวัติออเดอร์ หน้าจอส่วนนี้มีทั้งภาษาอังกฤษและไทย
- **ทีมงาน (admin):** ตรวจสลิป อนุมัติ โพสต์ลูกหนี้ เติมหรือปรับเครดิต และเปิด/ปิด module ผ่าน `#/admin`
- **สองกระเป๋า:** โควตาต่อรอบเดือนของแพ็กสัญญา (ใช้ไม่หมดถือว่าหมดสิทธิ์) และเครดิตที่ซื้อเติม (ไม่หมดอายุ)

## 1.3 ขอบเขต

| ทำ | ไม่ทำ |
|---|---|
| หักเอกสารจากสองกระเป๋าตามลำดับ และคืนเมื่อการอ่านล้มเหลว | ทบโควตาข้ามรอบ หรือแบ่งจ่ายข้ามสองกระเป๋าในรายการเดียว |
| ขายแพ็กสัญญาและแพ็กเติม ด้วยการโอนเงินแล้วแนบสลิป | ตัดเงินออนไลน์ ตรวจสลิปอัตโนมัติ หรือออกใบกำกับภาษี (Carmen เป็นระบบหลักทางภาษี) |
| ใบเสนอราคาพร้อมเลขที่รันต่อเนื่อง | คืนเงินตามสัดส่วนเมื่อเปลี่ยนแพ็กกลางเทอม — คิดราคาเต็มทุกครั้ง |
| เปิด/ปิด module ต่อ BU แบบ opt-out | หน้าจอแก้แคตตาล็อกแพ็ก — แก้ผ่าน migration |
| AI Status ให้ Carmen | แจ้งเตือนเมื่อเครดิตใกล้หมด |
