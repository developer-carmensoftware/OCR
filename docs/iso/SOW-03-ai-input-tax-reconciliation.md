# 1. วัตถุประสงค์ และผู้ใช้งาน

ใบกำกับภาษีค่าธรรมเนียมบัตรเครดิตหนึ่งใบต้องลงทั้ง JV และทะเบียนภาษีซื้อ ถ้าคีย์ภาษีซื้อเองแยกต่างหาก ตัวเลขสองชุดอาจไม่ตรงกัน และใบที่ตกหล่นทำให้ยื่น ภ.พ.30 ไม่ครบ รายการนี้นำข้อมูลภาษีซื้อที่ AI อ่านแล้วเข้าสู่ทะเบียนภาษีซื้ออัตโนมัติ เพื่อให้เจ้าหน้าที่ตรวจกระทบยอดประจำเดือน
