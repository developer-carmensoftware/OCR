# 1. วัตถุประสงค์ และผู้ใช้งาน

ขอบเขตเดิม (SOW v1.0) รองรับเฉพาะใบกำกับภาษีค่าคอมมิชชันของ 4 ธนาคาร แต่โรงแรมรับชำระผ่านผู้ให้บริการ Payment Gateway หลายราย ซึ่งคิดค่าธรรมเนียม MDR และออกใบกำกับภาษีให้ทุกสิ้นเดือน ถ้าไม่ทำ เจ้าหน้าที่ต้องบันทึก JV ของ Gateway ด้วยมือ และภาษีซื้อของ Gateway ตกหล่นจนยื่น ภ.พ.30 ไม่ครบ คำขอเปลี่ยนแปลง CR-2026-001 ยื่นโดยผู้จัดการฝ่ายบัญชีและการเงินเมื่อ 18/06/2026 ระดับความสำคัญสูง

# 5. เกณฑ์การตรวจรับ

- ความแม่นยำในการดึง Tax ID เลขที่ใบกำกับ ยอดสุทธิ และ VAT จากตัวอย่างเอกสาร Gateway จริง ไม่น้อยกว่า 95%
- JV ของ Gateway มี Dr เท่ากับ Cr ไม่มีผลต่างเศษสตางค์
- ข้อมูลใบกำกับของ Gateway เข้าโมดูล Input Tax Reconciliation ครบ 100% ทุกรายการที่ผ่านการอนุมัติ JV
- ผ่านชุดทดสอบ TC-JV-PGW-001..015 (CR ระบุ TC-PGW-001..020 ใช้ SOW v1.2)
- ผู้จัดการฝ่ายบัญชีและเจ้าหน้าที่การเงินลงนาม UAT Sign-off Record
