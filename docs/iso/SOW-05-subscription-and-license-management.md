# 1. วัตถุประสงค์ และผู้ใช้งาน

ทุกการอ่านเอกสารด้วย AI มีต้นทุน แม้เป็นระบบภายในองค์กร ก็ต้องมีแพลตฟอร์มกำหนดว่าหน่วยงานใช้โควตาเท่าใด ออกใบเสนอราคา (Proforma Invoice) ค่าบริการ ตรวจหลักฐานการชำระเงิน และควบคุมสิทธิ์การใช้งาน รายการนี้พัฒนาแพลตฟอร์มดังกล่าวพร้อมระบบหลังบ้านสำหรับผู้ดูแลระบบ (Admin Console)

# 2. ขอบเขตงาน

<!-- widths!: 55,45 -->
| ทำ | ไม่ทำ (หรืออยู่ในรายการอื่น) |
|---|---|
| ออก Proforma Invoice ค่าบริการ AI ตามแพ็กเกจหรือโควตาการสแกนเอกสาร | ตัดเงินออนไลน์ (ตัวระบบรับหลักฐานการโอน ไม่เชื่อม payment gateway) |
| คำนวณค่าบริการตามโควตา (Transaction Quota Usage) | ออกใบกำกับภาษี — เป็นหน้าที่ของ Carmen ERP |
| Admin Console ตรวจหลักฐานการชำระเงิน (Payment Slip Verification) และปล่อย License / Token | — |
