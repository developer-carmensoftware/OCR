# 1. บทนำ

## 1.1 วัตถุประสงค์

ใบกำกับภาษีค่าธรรมเนียมบัตรเครดิตหนึ่งใบต้องลงใน Carmen สองที่ คือ JV และทะเบียนภาษีซื้อ เดิมพนักงานบัญชีต้องคีย์ภาษีซื้อเองซ้ำกับ JV ตัวเลขสองชุดจึงไม่ตรงกันได้ และใบที่ลืมคีย์คือภาษีซื้อที่ขอคืนไม่ได้ในงวดนั้น ระบบนี้สร้างรายการภาษีซื้อ (`inputTaxRec`, Source `ACTX`) ใน Carmen จากยอดชุดเดียวกับ JV ให้อัตโนมัติ

รายละเอียดการออกแบบอยู่ใน FRD-09 ซึ่งเป็นเอกสารออกแบบ (Software Design) ของงานนี้

## 1.2 ผู้ใช้และบริบท

- **ผู้ใช้:** พนักงานบัญชีที่ post JV จาก RS-01 (wizard), RS-06 (อีเมล) และคิวของ RS-08
- **ค่าใช้จ่าย:** ไม่เรียก LLM และไม่หักเครดิต ใช้ผลการอ่านที่จ่ายไปแล้ว

## 1.3 ขอบเขต

| ทำ | ไม่ทำ (ผู้ใช้ทำเอง หรืออยู่ในงานอื่น) |
|---|---|
| ยื่นภาษีซื้อหลัง JV จาก wizard step 4 และจากอีเมล | แก้รายการภาษีซื้อหลังยื่นแล้ว — แก้ใน Carmen |
| ยื่นย้อนหลังจากคิว ภายในกรอบ 6 เดือน | ยื่นหลังเลยกรอบ 6 เดือน |
| บันทึกว่า "คีย์ใน Carmen เองแล้ว" | ตรวจว่ามีคนคีย์ใบเดียวกันใน Carmen แล้วหรือไม่ — Carmen ไม่มี API ค้น |
| ภาษีซื้อของ settlement report ของ KBANK จากแถวรวม | เอกสารหลายอัตราภาษีในใบเดียว — ยื่นเป็นรายการเดียวตามอัตรารวม |
