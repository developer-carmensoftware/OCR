# 1. วัตถุประสงค์ และผู้ใช้งาน

ระบบเดิมให้ AI ประมวลผลเอกสารเบื้องหลังแล้วส่งรายการเข้า ERP เอง ฝ่ายบัญชีจึงมองไม่เห็นรายการก่อนบันทึกบัญชีจริง ซึ่งขัดกับหลักการควบคุมภายใน คำขอเปลี่ยนแปลง CR-2026-002 ยื่นโดยผู้จัดการฝ่ายบัญชีและการเงินเมื่อ 24/09/2026 ระดับความสำคัญสูง ให้พัฒนาหน้าจอ AI Transaction เป็นศูนย์กลางมอง ตรวจทาน และควบคุมรายการที่ AI สร้าง โดยจัดการเฉพาะรายการที่มีเงื่อนไขพิเศษ (Management by Exception)

# 5. เกณฑ์การตรวจรับ

- เอกสารที่ตรงเงื่อนไข Always Review หรือข้อมูลไม่ครบ ถูกดึงเข้าคิว Pending Review ถูกต้อง 100%
- เจ้าหน้าที่เปิดภาพเอกสารพร้อมไฮไลต์ตำแหน่งข้อมูลคู่กับการแก้ฟิลด์ Dr./Cr. ได้สมบูรณ์
- ระบบไม่ให้บันทึกผ่านรายการเมื่อ Dr ไม่เท่ากับ Cr
- ทุกการแก้ไขและอนุมัติมี User ID วันที่-เวลา และค่าที่เปลี่ยนครบ
- ผ่านชุดทดสอบ TC-UI-TRANS-001..020 (รายงานใน MR #13)
